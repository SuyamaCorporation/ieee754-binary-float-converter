# IEEE754浮動小数点2進/16進数コンバーター

10進数・HEX文字列を入力すると、IEEE 754 32bit単精度と64bit倍精度の両フォーマットで符号・指数部・仮数部にビット分解して可視化します。
各ビットは符号（赤）・指数部（青）・仮数部（緑）の3色でセル表示され、バイアス計算・真の指数値・仮数の実数値も詳細表示します。
NaN・±Infinity・非正規化数・±0などの特殊値を自動判定してラベル表示します。
π≒3.14159・0.1・NaN・Infinityなどのクイック入力ボタンで代表的な値をすぐに確認できます。

## 使い方

入力欄に数値を入力するとリアルタイムで変換されます。「HEX (32bit/64bit)」モードに切り替えると16進数から逆デコードもできます。
